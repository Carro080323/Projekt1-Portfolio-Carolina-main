HTMLs historia

Utforska webbens utveckling och tillgänglighet på webben.

ARPANET

Internet har sina rötter i militära projekt som ARPANET, utvecklat under 1960-talet av det amerikanska försvaret. Syftet var att skapa ett robust kommunikationssystem som kunde fungera även om delar av nätverket gick ner.

Tim Berners-Lee och webben

Webben föddes i början av 1990-talet när Tim Berners-Lee utvecklade World Wide Web (WWW) på CERN. Målet var att göra det enkelt för forskare att dela information via länkar mellan dokument.

W3C grundades 1994 och ansvarar för att utveckla och standardisera webben.

World Wide Web och W3C

WWW är ett system av webbplatser kopplade via hyperlänkar, medan internet är infrastrukturen som möjliggör kommunikation.

W3C skapar riktlinjer och standarder för HTML, CSS och andra webbteknologier.

Läs mer på W3C

JavaScript och DOM

JavaScript gör webbsidor interaktiva och arbetar tillsammans med DOM (Document Object Model), som gör det möjligt att manipulera HTML-strukturen.

HTML5

HTML5 introducerade nya funktioner som video, ljud, geolocation och förbättrade formulär. Det gjorde webben mer modern och kraftfull.

Responsiv design och webbutveckling

Mellan 2010 och 2019 ökade mobilanvändningen vilket ledde till responsiv design och nya CSS-tekniker.

Frameworks som React och Angular förenklade utvecklingen av webbappar.
