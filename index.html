Välkommen!

Hej! Jag heter Carolina och det här är min portfolio. Här visar jag några av mina projekt där jag lärt mig HTML, CSS och grunderna i webbutveckling.

Mina Projekt

Här kan du se två större webbutvecklingsprojekt som jag har arbetat med.

Projekt 2

I detta projekt utforskar jag grunderna i HTML, dess historia och hur DOM fungerar. Jag bygger en flersidig webbplats med fokus på struktur, semantik och hur webben är uppbyggd bakom kulisserna.
Projekt 3

Jag arbetar med att göra en befintlig webbplats responsiv så att den fungerar på mobil, surfplatta och dator. Fokus ligger på Flexbox, Grid, media queries och att skapa en bra användarupplevelse på alla skärmstorlekar.

 Mina Uppgifter

Här hittar du olika webbutvecklingsuppgifter, där jag fokusert på vissa specifika områden.

Klicka på korten för att se uppgifterna.

Uppgift 1

Jag lär mig grunderna i HTML och CSS samt hur man arbetar med Live Server, GitHub och W3C Validator. Fokus ligger på att förstå hur en webbsida byggs från grunden och hur man publicerar projekt på ett korrekt sätt.
Uppgift 2

Vi arbetar med semantisk HTML och bygger en strukturerad webbsida med header, main och footer. Jag tränar på god praxis, tillgänglighet och hur man organiserar innehåll med rätt element.
Uppgift 3

Jag tränar på länkar och sökvägar i HTML, inklusive absoluta och relativa länkar samt bokmärkes- och e-postlänkar. Fokus ligger på att förstå hur filer och sidor hänger ihop i en webbstruktur.
Uppgift 4

Jag arbetar med bilder, video och iframe i HTML och lär mig hur man korrekt lägger in och stylar media. Vi fokuserar även på optimering och hur man undviker att bilder blir felvisade.
Uppgift 5

Vi introduceras till Flexbox och hur det används för att skapa enkla och responsiva layouter. Jag tränar på att centrera innehåll och bygga navigationsmenyer med modern CSS.
Uppgift 6

Jag lär mig CSS Grid och hur man bygger mer avancerade layouter i två dimensioner. Fokus ligger på struktur, placering av element och hur grid-system kan användas i riktiga webbprojekt.
Uppgift 7

Vi jobbar med CSS position och lär oss hur man placerar element exakt på sidan. Jag tränar även på fast navigation och hur position påverkar layout och flöde.
Uppgift 8

Jag arbetar med CSS-animationer och transitions för att skapa rörelse och interaktiva effekter. Fokus ligger på att förbättra användarupplevelsen med små visuella detaljer.
